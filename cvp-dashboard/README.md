# AquaPure Industries: CVP & Break-Even Analysis Dashboard

## Project Overview
This professional-grade financial dashboard was developed for the **Cost & Management Accounting** course at **Lovely Professional University**. It provides a comprehensive decision-support system for **AquaPure Industries**, specifically focusing on their 1-Litre water bottle product line.

The application utilizes **Cost-Volume-Profit (CVP)** analysis to help managers understand the relationship between costs, volume, and profit.

## Objectives
- Determine the Break-Even Point (BEP) in units and currency.
- Analyze the Margin of Safety (MoS) for risk management.
- Visualize the impact of variable and fixed costs on profitability.
- Perform Sensitivity Analysis for various business scenarios.
- Calculate units required to achieve target profits.

## Key Features
- **Real-time Calculation Engine**: Updates all KPIs and charts instantly as inputs change.
- **Interactive Visualizations**: High-quality charts powered by Chart.js (BEP, Profit Trend, Revenue vs Costs).
- **Sensitivity Analysis**: Automated table showing how ±10% and ±20% changes in factors impact profit.
- **Strategic Insights**: AI-like logic to provide qualitative business feedback based on numerical results.
- **Premium UI**: Glassmorphic design, dark/light mode, and fully responsive layout.
- **Export Tools**: One-click CSV export and Print-to-PDF functionality.

## Technologies Used
- **Frontend**: HTML5, CSS3 (Modern Flexbox/Grid)
- **Scripting**: Vanilla JavaScript (ES6+)
- **Charts**: Chart.js
- **Icons**: Font Awesome
- **Typography**: Google Fonts (Poppins)
